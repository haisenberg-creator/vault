# Tauri + React + Typescript

This template should help get you started developing with Tauri, React and Typescript in Vite.

## Getting Started

For full setup instructions, system prerequisites, and development commands, see [SETUP.md](file:///d:/Projects/checklist-app/SETUP.md).

### Quick Commands

```bash
# Install dependencies
npm install

# Run Desktop Application in Dev Mode
npm run tauri dev

# Run Web-only UI in Dev Mode
npm run dev

# Run Test Suite
npm test
```
