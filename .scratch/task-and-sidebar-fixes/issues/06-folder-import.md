# 06 — Folder Import & Text Conversion

**What to build:** Adds an "Import Folder" action that opens a native system dialog. Recursively copies the selected folder into the Vault and automatically changes any `.txt` extensions to `.md` on import.

**Blocked by:** None — can start immediately

**Status:** completed

- [x] An "Import Folder" button exists in the interface.
- [x] Clicking the button opens a native operating system folder picker.
- [x] Selecting a folder copies it and its contents into the current Vault root.
- [x] Any `.txt` files inside the imported folder are automatically converted/renamed to `.md`.
