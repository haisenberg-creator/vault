# 05 — Priority Drag-and-Drop Reordering

**What to build:** Enables Lexical drag-and-drop functionality specifically for tasks, allowing users to grab a task and drop it underneath a Priority Header to change its priority level on the fly.

**Blocked by:** 04 — Priority Buttons and Header Styling

**Status:** completed

- [x] Users can drag a `TaskNode` within the editor.
- [x] Users can drop the `TaskNode` directly underneath a Priority Header (like `## Urgent`).
- [x] The dropped task persists in its new location without breaking surrounding text or markdown formatting.
