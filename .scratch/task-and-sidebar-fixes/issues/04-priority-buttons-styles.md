# 04 — Priority Buttons and Header Styling

**What to build:** Adds "Urgent", "High", and "Low" buttons to the editor toolbar that instantly inject the corresponding Markdown priority headers. Adds custom CSS so these headers are distinctly color-coded in the editor.

**Blocked by:** None — can start immediately

**Status:** completed

- [x] Three new buttons ("Urgent", "High", "Low") are present in the editor toolbar.
- [x] Clicking a button inserts `## Urgent`, `## High`, or `## Low` at the cursor position.
- [x] The Priority Headers are distinctly color-coded in the editor view (e.g., Red for Urgent, Orange for High).
